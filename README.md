# SVG Importer (Hotel Hideaway fork)

Unity package `com.hotelhideaway.svgimporter`: [SVG Importer](https://github.com/jaroslavstehlik/svgimporter) by Jaroslav Stehlik,
in Unity Package Manager layout, with fixes used by Hotel Hideaway.

Install by adding the release tag to the project's `Packages/manifest.json`:

```json
"com.hotelhideaway.svgimporter": "https://github.com/pocketzworld/svgimporter.git#v1.1.6-h4k.1"
```

- Script `.meta` GUIDs are kept identical to upstream, so existing assets keep their references.
- Every change ships under a new version in `package.json` and a matching tag.
- Licence: see [LICENSE](LICENSE) (upstream copyright notices must be kept).

## Upstream README

Unity Plugin for importing SVG files and creating a GPU friendly mesh representation of them.

# Compatible with
• Adobe Illustrator

• Adobe Flash

• Corel Draw

• Affinity Designer

• Inkscape

# supported features
• Simple & complex shapes

• Strokes and fills with transparency

• Linear Gradients

• Radial Gradients

• Conical Gradients

• Holes

• Clip Paths "absolute"

• Symbols

# unsupported features
• Masks “SVG mask will be not supported due to hardware limitations”

• Text “most graphics editors can convert text to curves”

• Filter Effects - blur, drop shadow, glow, bevel

• SVG Animation

• Embeded Images
